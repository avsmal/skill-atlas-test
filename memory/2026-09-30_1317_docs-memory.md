# PR #9 — Shared memory folder and AGENTS.md rules for it

- **Date/time:** 2026-09-30, discussion started 13:14 UTC, PR opened 13:17 UTC
- **Branch:** `docs/memory`
- **PR:** https://github.com/avsmal/skill-atlas-test/pull/9

## What was asked
- Create `memory/` and fill it from previous discussions; every discussion that ended in a PR gets
  its own file with date, time and branch in its name.
- The user then added a *Shared memory* section to `AGENTS.md` (read `memory/` before a task,
  always update it, remember feedback from rejected PRs) and asked for a check.

## What was decided / built
- One file per PR, `YYYY-MM-DD_HHMM_<branch>.md`, time = PR open time in UTC, `/` → `-`.
  `notes.md` holds non-PR discussions and working preferences.
- Files for PRs #6 and #7 were reconstructed from PR descriptions (sandbox transcripts aren't local).
- Review of the user's AGENTS.md edit led to:
  - `## Shared memory` as a real heading (it was a list item inside *Definition of done*).
  - The memory file is added to the same branch after `gh pr create` (the name needs the PR open
    time) and is part of the definition of done.
  - Feedback from a rejected PR goes in via a new branch/PR, because the rejected branch never merges.
  - No index table in `memory/README.md`: parallel PRs would all edit it and conflict.
  - Fixed the old typo "Integrations test for every cast" → "Integration tests for every case".
